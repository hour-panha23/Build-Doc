1. System Architecture & Tech Stack

The dashboard is engineered as a modern Single Page Application (SPA) powered by Next.js 15 (App Router), React 19, and TanStack Query v5. It securely proxies all backend traffic through server route handlers to hide internal secrets.

Technology Stack

Layer Technology Purpose
Framework Next.js 15.1 + React 19 App router, server-side route handlers, responsive UI layout
State & Fetching TanStack React Query v5 Server state caching, background refetching, mutations, optimistic updates
Real-Time Layer Socket.IO Client v4.8 Persistent connection to /notifications gateway, heartbeat diagnostics
Styling & Icons Tailwind CSS + Lucide Icons Clean modern dark-mode design system and operational iconography
BFF Proxy Next.js Route Handlers /api/proxy/[...path] forwards client requests to signal-service-api

3. Module 1: Real-Time Event Monitoring (/monitoring)

The monitoring console (src/components/RealtimeMonitor.tsx) provides live visibility into active connections, real-time message streams, and connection performance metrics.

⚡ Dual Connection Modes
App Mode: Connects with a specific projectId and secret to observe tenant-level traffic.
Admin Mode: Emits an admin_subscribe handshake, granting global visibility over broadcast traffic and internal server logs across all projects.
⏱️ Real-Time RTT Latency & Diagnostic Health
Continuously benchmarks round-trip ping/pong times to the WebSocket gateway:
• < 100ms Optimal throughput
• 100ms – 300ms Moderate delay
• > 300ms Network congestion / High latency
Also tracks lastDisconnectReason and provides auto-reconnect retry counter.
🎯 S2S Test Emission Console
Allows operators to dispatch test payloads directly from the dashboard across 5 distinct broadcast scopes: Broadcast, Project, App, Room, or targeted User.

4. Module 2: Project Management (/project)

The Project Management module (src/components/ProjectManagement/) controls project containers, tenant isolation, and cryptographic secrets.

Project Data Contract

Field Type Description
project_id string Unique project ID (e.g. project_e4de70df23a96fdb) passed in headers
name string Human-readable display name
secret_key string 64-character hex HMAC secret (revealed via Secret Modal)
webhook_url string|null HTTP URL receiving asynchronous event notifications
is_active boolean Active status toggle (inactive projects reject all incoming emissions)
⚠️
Secret Key Regeneration Impact:
Regenerating a project's secret key will immediately invalidate all active Laravel backend signatures and frontend client connection tickets. Ensure backend .env files are updated simultaneously.

Project Service Endpoints (src/services/project/project.service.ts)

TypeScript 
// Fetch paginated project list
export async function listProject(params: OffsetPaginationPayload<Project>);

// Register new project
export async function createProject(param: Partial<CreateProjectParam>);

// Toggle project status
export async function enableProject(id: string);
export async function disableProject(id: string);

// Rotate HMAC Secret Key
export async function regenerateSecret(id: string);

// Delete project
export async function deleteProject(id: string);

5. Module 3: Hardware Device Management (/device)

The Device Management module (src/components/DeviceManagement/) configures biometric, RFID, and facial recognition terminals (e.g. AiFace hardware devices) that connect to Signal's HardwareGateway on port 8088.

Device Data Contract

Field Type Description
device_name string Descriptive label (e.g. Main Entrance Gate A)
device_serial string Hardware serial number (sn) reported in terminal packets
project_id string Associated project identifier
app_id string Target application identifier
room string Destination room/channel (e.g. attendance_kiosk_gate1)
event string Real-time event name emitted upon scan (e.g. student_scanned)
webhook string Backend verification endpoint (e.g. Laravel access scan API)
💡
Dynamic Room Re-Routing:
Editing a terminal's room or event in this dashboard updates the Redis route cache immediately. You do not need to restart or re-configure physical terminal firmware to change destination broadcast rooms.

Device Service Endpoints (src/services/device/device.service.ts)

TypeScript 
// Fetch registered terminal list
export async function listDevices(params: OffsetPaginationPayload<Device>);

// Register a new physical terminal
export async function createDevice(data: CreateDevice);

// Update room assignment or event name
export async function updateDevice(id: number | string, data: UpdateDevice);

// De-register a hardware terminal
export async function deleteDevice(id: number | string);

6. Internal API & BFF Proxy Architecture

All API communication is routed through the Next.js server route handler /api/proxy/[...path] to protect API credentials and backend endpoints from client browser exposure.

TypeScript (src/config/api.ts) 
const INTERNAL_API_BASE = "/api/proxy";

export const API_ENDPOINTS = {
  auth: {
    login: "/api/proxy/auth/login",
    logout: "/api/proxy/auth/logout",
    refresh: "/api/proxy/auth/refresh",
  },
  project: {
    listProject: "/api/proxy/projects/list",
    createProject: "/api/proxy/projects/create",
    regenerateSecret: (id: string) => `/api/proxy/projects/regenerate-secret/${id}`,
    updateProject: (id: string) => `/api/proxy/projects/update/${id}`,
    enableProject: (id: string) => `/api/proxy/projects/enable/${id}`,
    disableProject: (id: string) => `/api/proxy/projects/disable/${id}`,
    deleteProject: (id: string) => `/api/proxy/projects/delete/${id}`,
  },
  device: {
    listDevices: "/api/proxy/devices/list",
    createDevice: "/api/proxy/devices/create",
    updateDevice: (id: string) => `/api/proxy/devices/update/${id}`,
    deleteDevice: (id: string) => `/api/proxy/devices/delete/${id}`,
  },
} as const;
